# **Mental health trajectories of religious minorities and majorities from childhood to early adulthood across Ethiopia, India, Peru, and Vietnam**

### Github project title: mental-health-trajectories-younglives

This project explores the mental health trajectories of religious minority and majority young people across four countries in the Young Lives dataset.

The data from Young Lives is accessed via the UK Data Service on an end user license and not synced with GitHub here.

The structure of the folder is:

mental-health-trajectories-younglives/
├── .git/ ← hidden tracking folder
├── .gitignore
├── README.md
├── mental-health-trajectories-younglives.Rproj ← R Project\
├── pre-processing.R ← pre-processing script
├── analysis.R ← analytical script
└── data/ ← Young Lives data (ignored by git)
